# Rules

- Pull requests are turned off during early development. Commit straight
  to `main` and push.
- Refactor freely with new commits. Rewriting pushed history (amend,
  squash, force push) is fine only while this repository is private and has
  a single writer; once others clone it, fix things with new commits.
- Keep code and docs free of any one organization's, person's or machine's
  names.
- Copy a part in from elsewhere only when it is polished and works on its
  own: it installs and runs from this repository alone, its tests pass,
  and its docs are short and match what it does.
